# 🚀 Хакатон Агрегатор

Веб-приложение для поиска и участия в IT-хакатонах с возможностью фильтрации, календарем событий и личным кабинетом.

## 📋 О проекте

**Hackathon Aggregator** — это фронтенд-приложение, разработанное в рамках дисциплины «Системная и программная инженерия» (РТУ МИРЭА, ИКБО-42-23). Приложение позволяет пользователям:

- Регистрироваться и авторизовываться в системе
- Просматривать актуальные IT-мероприятия (хакатоны)
- Фильтровать события по датам, сложности и ключевым словам
- Просматривать календарь с визуальным отображением дней проведения хакатонов
- Записываться на хакатоны и отслеживать свои заявки
- Редактировать профиль (имя, город, навыки)
- Настраивать тему оформления (светлая/темная) и размер шрифта

## 🛠 Технологии

- **Чистый JavaScript (ES6+)** — без фреймворков
- **CSS3** — адаптивный дизайн, CSS Grid, Flexbox, анимации
- **HTML5** — семантическая разметка
- **Font Awesome 6** — иконки
- **LocalStorage** — хранение данных пользователей и настроек
- **ES Modules** — модульная архитектура

## 🚀 Установка и запуск

### Локальный запуск

1. **Клонируйте репозиторий:**
```bash

git clone https://github.com/your-username/hackathon-aggregator.git
cd hackathon-aggregator
```

Откройте приложение:

Просто откройте файл index.html в любом современном браузере

Или используйте локальный сервер:

```bash

# Если у вас установлен Python
python -m http.server 8000

# Или с помощью Node.js (если установлен live-server)
npx live-server
Перейдите по адресу: http://localhost:8000
```

Тестовый аккаунт
Для быстрого входа используйте тестовые данные:

Email: test@test.ru

Пароль: 123456

📖 Функциональность
1. Авторизация и регистрация
Регистрация: создание нового аккаунта с указанием имени, email, пароля, города и навыков

Вход: авторизация существующего пользователя

Хранение: все данные сохраняются в localStorage браузера

2. Главная страница (список хакатонов)
Отображение всех хакатонов в виде карточек

Фильтрация по:

Дате начала (от/до)

Сложности (легкий, средний, сложный)

Поиск по названию

Календарь-превью с выбранными датами

3. Календарь событий
Полноценный календарь на месяц

Переключение между месяцами

Подсветка дней с хакатонами

Подсветка текущего дня

Клик по дню — просмотр хакатонов в этот день

Легенда с пояснениями

4. Профиль пользователя
Просмотр личных данных (имя, email, город, навыки, дата регистрации)

Редактирование профиля (изменение имени, города, навыков)

Список записанных хакатонов с возможностью отмены регистрации

Статусы заявок (на рассмотрении, одобрено, отклонено)

5. Настройки
Тема оформления: светлая / темная

Размер шрифта: маленький / средний / большой

Уведомления: вкл/выкл

Компактный вид: вкл/выкл

6. Запись на хакатоны
Кнопка "Записаться" на каждой карточке хакатона

Уведомления об успешной записи

Защита от повторной записи

Отображение записанных хакатонов в профиле

Особенности реализации
Архитектура
Проект построен на модульной архитектуре с разделением ответственности:

Services — бизнес-логика и работа с данными

Components — UI компоненты, рендеринг и обработка событий

Models — модели данных (соответствуют отчету, раздел 3.2)

Utils — вспомогательные функции

Хранение данных
Все данные сохраняются в localStorage:

hackathon_users — список зарегистрированных пользователей

hackathon_current_user — текущий авторизованный пользователь

user_settings_{userId} — настройки пользователя (тема, шрифт и т.д.)

user_hackathons_{userId} — список хакатонов, на которые записан пользователь
