# 🚀 Хакатон Агрегатор

Веб-приложение для поиска и участия в IT-хакатонах с возможностью фильтрации, календарем событий и личным кабинетом.

## 📋 О проекте

**Hackathon Aggregator** — это проект, разрабатываемый в рамках дисциплины «Системная и программная инженерия» (РТУ МИРЭА, ИКБО-42-23). 

Система представляет собой клиент-серверное приложение, которое агрегирует информацию об IT-мероприятиях с различных площадок (Timepad, Codenrock, Telegram) и предоставляет пользователям удобный интерфейс для поиска, фильтрации и отслеживания хакатонов.

## 🏛 Архитектура проекта

Проект разделен на логические модули (микросервисная архитектура MVP) и использует единый монорепозиторий:

1. **Frontend (Клиентская часть):** Отвечает за UI/UX, рендеринг календаря и взаимодействие с пользователем. Реализован на чистом JavaScript (ES6+), HTML5 и CSS3.
2. **Backend (Серверная часть):** REST API на Python (FastAPI), отвечающее за бизнес-логику, авторизацию пользователей и выдачу списка мероприятий.
3. **Парсеры (Data Engineering):** Изолированные скрипты на Python, которые по расписанию собирают данные с внешних API площадок-доноров, нормализуют их и складывают в базу данных.
4. **База данных:** PostgreSQL для хранения связей между пользователями, их навыками и сохраненными хакатонов.

## 👥 Команда и распределение ролей

Разработка ведется по итерационной методологии с использованием фреймворка **Scrum** (двухнедельные спринты).

* **Руководитель проекта / Data Engineer (Product Owner):** Управление бэклогом, архитектура баз данных, написание скриптов-парсеров.
* **Фронтенд-разработчик:** Создание пользовательского интерфейса, верстка карточек и интеграция с REST API.
* **Бэкенд-разработчик:** Проектирование серверной логики, маршрутизации и эндпоинтов на Python.
* **Аналитик / QA (Scrum Master):** Сбор требований, ведение документации проекта, контроль качества и тестирование инкрементов продукта.

1. Клонируйте репозиторий:
   ```bash

   cd hackathon_agregator
   ```

3. Запустите клиентское приложение из папки /frontend.
